WhatHow
Where it startsThe Add to board ▾ menu, everywhere a work item has one: its drawer, a search row's Add ▾, the board picker. ＋ New board from this item… is first; under it are the open boards it could join as a related item, as today.
Default name#<id>_<title>, e.g. #59851_Q4-INTE-CORE-015 Baggage Bundle Choice Display & Ancillary Clarification "Air Arabia", cut to the board-name limit at a word, and editable. If that name is already used in the project, the dialog says so and offers to open that board instead.
ProjectFilled from the item's mapping (iteration, team, area or project); else the project used last. "Remember for team NDC1 - Commandos" saves the mapping, as Start does.
Main itemOn by default: the item becomes the board's main item, kept in full and diffed on sync, as with Start. If it is already another board's main, the dialog says which, and the new board takes it as a related item instead.
First cycleThree choices. New cycle (default): an empty cycle with the board's name, not recording. New cycle and record now: off while another cycle records this project, and it says which one. No cycle: add or attach one later from the board.
Extra (optional)Children and links as related items (count shown). Fetch the item's attachments to the board (needs the token). Both off by default.
CreateOne request: the board, its cycle and the main-item link, made together, so a failure leaves nothing half made. The drawer then shows "★ Main item of #59851_…" with Open board ▾ (Open board, Record, New re-test cycle). Nothing is written to Azure.
