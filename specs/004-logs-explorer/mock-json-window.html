⤢ Open - JSON / XML detector, formatted / tree view, read-only

Mock of the value window from the Logs explorer. Pick a sample value, it is checked as the window opens. Static data, nothing talks to Alfred.

1The window opens with the value exactly as stored (as today).
2It is checked for JSON or XML as the window opens - no click. Found → a bar offers Format, Tree or Keep as is (and the switch appears). JSON stored as a string inside a string (escaped quotes) is unwrapped too, and says so. Not found → the text stays exactly as stored, and a { } Check format button explains why: it tells whether it looks like JSON or XML and where it breaks (line, column, the text around it - e.g. JSON cut off by the logger's length limit), or that it is plain text.
3Once detected, a switch stays in the header: Original · Formatted · Tree - "Original" is the unformat. Formatted is the same coloured view as call request/response bodies (JSON or XML colours); Tree is a collapsible tree, with Expand all / Collapse all - for XML each element is a node, its attributes listed as @name, its text as the value.
4Read-only everywhere - nothing can be edited. Find works in every view. Copy copies what you see (original or formatted text).
