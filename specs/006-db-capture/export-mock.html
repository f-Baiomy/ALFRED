Export mock - database statements. Three parts: 1 the export dialog (same dialog for call, selection and whole-cycle exports) gets one unchecked option; 2 the .html export's call card gets one closed "Database" block with a one-line headline - open it for flags, then statements as closed one-line rows, transactions as closed groups, each statement opening to its SQL, params and rows; 3 the .md export, same shape with <details> (shown raw and as GitHub renders it). Nothing is cut when included - every statement and stored row is still in the file, just folded.
