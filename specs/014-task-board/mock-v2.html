ODY-482 · Discount on checkout

A customer can enter one discount code at checkout.

Acceptance

  1. POST /orders returns 201.
  2. ORDERS.discount is stored with the applied value.
  3. An invalid code returns 422 and no order is created.
  4. No ERROR lines are logged.

Out of scope

  • Stacking several codes.
  • Pricing service latency.
