Call & report exports - redesign

Same design as the Relive exports

  • An answer first (verdict: "2 of 8 calls failed - POST /price answered 502…") and count tiles, then the existing About This Document - kept word for word, just laid out as a card.
  • Sticky contents on the left (every call with its status dot, nested like the call tree, with spacer labels), filter chips (All / Failed / Flagged / Inbound / Outbound), every call one card with its full URL, facts grid, and folds that start closed. Bodies keep today's searchable, copyable, flag-annotated block, now height-capped with its own scrollbar.
  • A short glossary at the end (inbound/outbound, split request · response, spacer, flagged line, Changed by Alfred) for a reader who was not there - or an AI agent.
  • .md gets the same order and the same parts (verdict quote, tiles row, full URL in the summary table, closed folds, glossary).

Kept exactly - nothing from today's .md / .html is dropped

  • Title with call count; "Exported" time, Succeeded, Failed, Total duration
  • About: What this is, Who called whom (depth sentence + tree), flow summary
  • About: "When each call ran" waterfall (HTML gantt / .md ASCII bands) with legend and up/down links
  • About: Caveats, Where the time went table + note, ordering note, flagged-lines note
  • Metadata table: Supplier, Credentials used, Environment, URL, API Key, Description
  • Summary table: #, Method, URL/Path, Status, Duration, Flagged count, anchors
  • Split internal calls: separate request / response blocks, "➡️ sent", Received time
  • Nesting by call depth (indent + rail), spacers placed by layoutSpacers, trailing spacers
  • Per call: Method, URL, Timestamp, Status, Duration, Error ("No response was received…")
  • Flagged Issues per block (Request/Response · Headers/Body), line number, line text, comment
  • Inline flag markers in bodies (.md "// ⚠ FLAGGED:", .html comment cards)
  • Headers + Body, pretty JSON/XML, never truncated; HTML find-in-block, prev/next, copy, lazy + virtual rendering
  • 🛠️ Changed by Alfred (request/response): rule · label · action · detail, synthetic note, Before / After
  • 🔌 WebSocket messages: direction, seq, time, action badge, content, binary size, original content
  • Footer: call count and flagged issue total; file names unchanged
  • Scenario report: per draft label, status, duration, error, every assertion with message, full body of failed drafts (redacted)
