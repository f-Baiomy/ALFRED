4 · What gets built

1. Colour in Markdown {red|text} (red, green, amber, blue, purple) - and Claude is told it exists.
2. Fixed fences drawn by the board: stats, chart (bar, hbar, line, pie, own SVG - no library), timeline (call waterfall), mermaid (flow/sequence/state diagrams; Mermaid loaded only when a comment has one, strict mode), [progress: a/b].
3. ```html live: sandboxed frame (opaque origin, CSP default-src 'none' + inline script/style + Alfred's own /board/lib/), auto height, ⤢ full screen, </> source, ⬇ .html, ⧉ copy. Runs on open; a ⏸ switch per browser if you prefer click-to-run.
4. Editor: toolbar entries + / menu for each block; live block opens a source box with a starter.
5. Claude: writing guide "when a picture helps" with examples of each; MCP tool descriptions list the fences; Claude reads them back as written.
6. Exports (.html draws both, .md keeps fences), docs/board.md, tests (sandbox attributes and CSP guarded by a test), browser check.
