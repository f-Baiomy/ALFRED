Find & replace: literal by default

Regex is opt-in. With regex on, the pattern is checked at save time. Patterns that can run away are refused, and anything that still runs long is stopped after 2 s. The match is then recorded as skipped and does not delay other calls.

Messages lane

Message actions apply to every message on a WebSocket whose opening request the rule matched. Each action picks a direction. A delay holds later messages on the same connection only, in order.
