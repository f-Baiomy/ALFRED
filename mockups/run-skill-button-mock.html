▶ runs in the cycle's chat - mock v2

A cycle belongs to the chat that runs /alfred-live / /alfred-listen for it - one chat per cycle. Every ▶ on that cycle's cards, its next-steps bar and its Task tab goes into that chat, whoever clicks: the chat runs the skill itself, with its own context, model and account. No new Claude run per click, no machine picker. No chat owns the cycle → the click tells you how to start one.

1. The flow

▶ on card #35→ Alfred: queued for the cycle's chat→ runner writes one line to the chat's watch→ the chat takes it between turns (board_run_take)→ runs /alfred-fix 35 itself→ ends it (board_run_end: done / failed + → line)
