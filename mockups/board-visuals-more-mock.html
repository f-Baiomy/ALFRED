The board fetches through Alfred's normal API (read-only) and redraws on the WebSocket "calls changed" signal - no polling. In the .md export a query block is written with its rows at export time. Claude reads the query and, when it asks, the rows.

B · data bridge: a live HTML block writes <script type="alfred/data" name="calls" src="calls?endpoint=POST /fare-confirm&since=fix">; the board checks it against a read-only allowlist (calls, statements, log lines, cycles), fetches, and posts the JSON into the frame as window.alfred.calls - updated live.
